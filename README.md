# Stock Price Prediction using LSTM + Transformer

## Overview

A Streamlit-based machine learning application that predicts future stock prices using historical market data and a hybrid LSTM + Transformer deep learning approach. The application also incorporates sentiment analysis for additional market context.

## Features

- Select different stock tickers
- Fetch historical stock data using yFinance
- Preprocess financial time-series data
- LSTM-based prediction
- Transformer-based pattern analysis
- Sentiment analysis
- Actual vs predicted price visualization
- Interactive Streamlit dashboard

## How It Works

1. Select a stock ticker.
2. Fetch historical market data using yFinance.
3. Preprocess and scale the data.
4. Use LSTM to learn sequential patterns.
5. Use Transformer layers to capture contextual relationships.
6. Incorporate sentiment analysis.
7. Generate future stock-price predictions.
8. Display results through the Streamlit dashboard.
